# Zoho Tech Blog (MERN)
1. `cd server && cp .env.example .env && npm i && npm start` (needs MongoDB; seeds 7 categories + admin user from .env)
2. `cd client && npm i && npm run dev` then open http://localhost:5173 and sign in at /admin.
Replace the placeholder logo in `client/src/components/Chrome.jsx` with the official Zoho SVG.
